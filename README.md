## 🌟 Fitur Utama

1. **Game Puzzle 3x3 Interaktif**:
   - Karya seni anime eksklusif menampilkan **Shedletsky** (dengan paha ayam 🍗 & pedang Telamon ⚔️) dan **1X1X1** (versi anime cute dengan efek glitch neon hijau 🟩) merayakan ulang tahun di antara bunga sakura.
   - Mendukung **Klik-untuk-Tukar** (*Click-to-Swap*) dan **Seret-dan-Lepas** (*Drag-and-Drop*).
   - Indikator Jumlah Langkah, Timer Stopwatch, dan tombol **"✨ Bantu Selesaikan"** (Auto-Solve dengan animasi otomatis).
   - Tombol **"🔍 Acuan Gambar"** untuk melihat target susunan puzzle.

2. **Pembukaan Kotak Hadiah 3D (*Gift Box Reveal*)**:
   - Begitu puzzle tersusun lengkap, kotak hadiah pink berpita emas akan bergoyang & membuka penutupnya.
   - Disertai ledakan konfeti, sinar cahaya glowing, dan musik selebrasi!

3. **Kartu Surat Ucapan Ulang Tahun (*Typewriter Effect*)**:
   - Surat ucapan dengan efek mengetik otomatis (*Typewriter animation*).
   - **Kustomisasi Nama & Pesan**: Pengguna dapat mengubah nama penerima (misal: "Amanda 💖") dan isi teks ucapan langsung di website lewat modal edit.

4. **Karakter Easter Eggs Interaktif**:
   - 🍗 **Shedletsky's Chicken**: Mengeluarkan hujan paha ayam terbang dengan suara cluck lucu!
   - ⚔️ **Telamon Sword**: Efek tebasan pedang menyala di layar.
   - 🟩 **1X1X1 Glitch**: Mengaktifkan mode layar neon glitch matrix Forsaken Roblox selama 3 detik.
   - 🌸 **Hujan Bunga Sakura**: Hujan kelopak bunga sakura dan hati.

5. **Audio & Visual Experience**:
   - **Pemutar Musik BGM Loop**: Melodi *Happy Birthday* anime synth (bisa diputar / di-mute).
   - **Efek Suara Synthesizer Web Audio API**: Suara swap tile, victory, tebasan pedang, cluck ayam, & glitch.
   - **Canvas Particle Engine**: Kelopak bunga sakura melayang lembut di latar belakang.
   - **Mode Tema**: Saklar pergantian tema antara *Soft Sakura Pink* dan *Dark Matrix Glitch 1X1X1*.
