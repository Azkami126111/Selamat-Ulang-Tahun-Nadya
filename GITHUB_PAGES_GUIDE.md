## 🛠️ Langkah-Langkah Publish ke GitHub Pages (Hanya 2 Menit)

### Langkah 1: Buat Repository di GitHub
1. Buka [github.com](https://github.com) dan login (atau daftar akun gratis jika belum punya).
2. Klik tombol hijau **"New"** atau tanda **"+"** -> **New repository**.
3. Beri nama repository, misalnya: `ucapan-ulang-tahun` atau `birthday-surprise`.
4. Pilih **Public** (agar bisa diakses publik).
5. Klik **"Create repository"**.

### Langkah 2: Upload File Proyek
1. Buka folder [C:\Users\SMP BAS\Documents\birthday-forsaken-puzzle](file:///C:/Users/SMP%20BAS/Documents/birthday-forsaken-puzzle) di komputer Anda.
2. Di halaman repository GitHub Anda yang baru dibuat, klik tulisan **"uploading an existing file"**.
3. Drag (seret) & drop semua file dari folder `birthday-forsaken-puzzle`:
   - `index.html`
   - `style.css`
   - `script.js`
   - `package.json`
   - `README.md`
4. Klik tombol hijau **"Commit changes"**.

### Langkah 3: Aktifkan GitHub Pages (1-Klik)
1. Di halaman repository GitHub Anda, klik menu **Settings** (di tab bagian atas).
2. Di menu sebelah kiri, klik **Pages** (bawah bagian *Code and automation*).
3. Pada bagian **Build and deployment** -> **Branch**:
   - Ubah dari `None` menjadi **`main`** (atau `master`).
   - Folder biarkan **`/ (root)`**.
4. Klik tombol **Save**.
5. Tunggu sekitar 30 detik. Refresh halaman, Anda akan melihat pesan:
   > 🎉 **"Your site is live at https://username.github.io/repository-name/"**
